6. Distributed System Concepts Summary

API Gateway

Single entry point handling HTTP/WS client requests, managing routing, and converting REST calls into gRPC/AMQP protocol messages.

gRPC & Protobuf

High-performance binary RPC protocol over HTTP/2 with strongly-typed protocol buffers for ultra-low latency internal ML inference.

RabbitMQ Message Queue

Asynchronous AMQP message broker enabling non-blocking batch processing, queue persistence, and decoupling gateway from worker load.

Synchronous Processing

Blocking request-response model where the client waits for immediate computation output from the worker node before responding.

Asynchronous Processing

Non-blocking model returning instant enqueue status to client while batch consumer workers process queue messages out-of-band.

WebSockets & WebRTC

Full-duplex real-time communication protocol for browser signaling, paired with browser WebRTC media capture streams.
